item comes from a pilot finding or a known limitation that a producer hits on every video.

## 2. Storyboards that fit the clip model (Q1)

- `StoryboardJobInput` gains `clipDurations: number[] | null` (from the video route's model
  constraints at request time; null = no video model routed) and `wordsPerSecond` (from the voice
  profile's language and speed; default 2.5 for Vietnamese, 2.8 for English).
- Template `storyboard.v2` adds: "Each scene lasts exactly one of: 4, 6, 8 s" and "Narration per
  scene must fit its duration at about N words per second". New jobs use v2; execution keys change,
  so identical old storyboards are not reused across the template change (expected).
- Rule `scene_duration_allowed` (storyboard rules): a disallowed length is a rule issue; the
  existing repair call fixes it; still invalid → `OUTPUT_INVALID` as today.

## 3. Portable structured output (Q2)

- `ai_models.schema_mode` (`full` default, `basic`), set with `pnpm ai:registry model
set-schema-mode <modelKey> <full|basic>`; shown in `model list`.
- `basic` strips `pattern`, `format`, numeric bounds, length and item-count limits from the JSON
  schema sent to the provider; the response is validated with the full Zod schema and repaired as
  today. No behaviour change for `full` models.

## 4. Model choice for text stages (Q3)

The keyframe/clip `ModelSelect` on the Script and Storyboard panels (enabled LLM models that pass
routing for the task); the request's `modelKey` already exists in the API.

## 5. Review UX (Q4–Q6)

- Version list (Script & brief, Storyboard tabs): each pending version has Approve/Reject; the
  approved one is marked "in use". API unchanged (any pending version can be approved).
- Voice picker: `GET /ai/models/:modelKey/voices` (from the registry's media constraints) feeds a
  searchable select; free text remains possible only for models whose catalog lists no voices.
- Rule errors: the web shows `error.details` (already returned by the API) as a list; rule messages
  include the measured values.
- Voice-over panel: per scene "Narration 9.8 s, scene 8 s: 1.8 s too long" with the two fixes.

## 6. Captions (Q7)

Pure function in `@acf/media` (`segmentCaptions`), unit-tested on Vietnamese and English; the
renderer and the SRT export use it. Render QC unchanged.

## 7. Content-Security-Policy (Q8)

`apps/web/src/proxy.ts` sets `Content-Security-Policy` with a per-request nonce (`script-src
'self' 'nonce-…' 'strict-dynamic'`, `style-src 'self' 'unsafe-inline'` for Next's style tags,
`img-src 'self' data: blob:`, `media-src 'self' blob:`, `connect-src 'self'`, `frame-ancestors
'none'`, `base-uri 'self'`, `form-action 'self'`); Next applies the nonce to its scripts. Caddy keeps
the other headers.

## 8. Scheduled, off-VM backups (Q9)

`backup.sh`: after a verified backup, optional `gcloud storage cp -r` to
`gs://$BACKUP_GCS_BUCKET/acf/<name>/`; local pruning only after a successful copy (or when no bucket
is set). `backup-schedule install|remove|status` manages one cron line (02:15 UTC). Tested with a
stub `gcloud` on PATH. You create the bucket (instructions in DEPLOYMENT.md, with a lifecycle rule
for retention).

## 9. Risks

| Risk                                            | Mitigation                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------ |
| `basic` schema lets more invalid output through | Same local validation and one repair; failures stay `OUTPUT_INVALID`           |
| CSP breaks a page (inline script, media)        | E2E checks every page for violations before merge; report-only first if needed |
| Storyboard v2 changes output style              | Same instructions plus two constraints; capped real comparison in the report   |
| Cron on the VM fails silently                   | Log file per run; failure lines use the alert event `backup_failed`            |
